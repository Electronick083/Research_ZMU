Физическое размещение микросхем памяти на плате ZMU (со слов пользователя 2026-06-15). Привязка к логической разводке — см. [[eeprom-array-architecture]], [[assembled-image]].

## Топология
- **Два ряда по 5 микросхем**, один над другим (10 чипов всего).
- **Ряд 1 = ВЕРХНИЙ, ряд 2 = НИЖНИЙ.** Столбцы нумеруются слева направо 1..5.
- Столбец 1 = оба AT28C256; столбцы 2..5 = массив 8× X28C512 (по 2 чипа на столбец, верх/низ).

```
            столб1      столб2     столб3     столб4     столб5
ряд1 (верх) AT28C256#1  X28C512#1  X28C512#3  X28C512#5  X28C512#7
ряд2 (низ)  AT28C256#2  X28C512#2  X28C512#4  X28C512#6  X28C512#8
```

## Привязка к логике (важные следствия)
- **Верхний ряд X28C512 = chip1,3,5,7 = БАНК A** (нечётные). **Нижний ряд = chip2,4,6,8 = БАНК B** (чётные). Т.е. ряд = банк.
- **Столбец 1:** верх = AT28C256 **#1 = identity/config** ([[at28c256-chip1-verified]]); низ = **#2 = журнал/NVM** ([[at28c256-chip2-unstable]]).
- Соответствие столбцов байтовым лейнам массива НЕ монотонно (лейны 7/8 и 5/6 переставлены, см. [[assembled-image]]):
  - столбец 2 (chip1/2) = byte0 (LSB)
  - столбец 3 (chip3/4) = byte1
  - столбец 4 (chip5/6) = byte3 (MSB)
  - столбец 5 (chip7/8) = byte2

## Практическое (rework)
- Доказанный дефект D00109 = 2 битых байта в **chip1 банка A** = **ВЕРХНИЙ ряд, столбец 2**. Это физическая позиция чипа под перешивку/замену (`512-1_FIXED.bin`). См. [[crash-unit-d00109]].

**Ориентация:** ключ (вывод 1 / выемка) у всех корпусов смотрит ВВЕРХ (к верхнему краю платы / к ряду 1). См. [[project-status]].
