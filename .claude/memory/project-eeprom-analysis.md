Проект в `D:\Claude\ZMU` посвящён анализу подключения параллельных (parallel) микросхем EEPROM в некотором устройстве.

**Why:** Стартовый контекст, заданный пользователем 2026-06-08.

**How to apply:** Ожидать работу с распиновкой EEPROM (адресные/данные/управляющие линии: A0..An, D0..D7, CE/OE/WE), схемами подключения, дампами памяти. Возможны фото/сканы платы, datasheet'ы, дампы. Хранить артефакты и заметки в папке проекта. См. [[memory-location-in-project]].
