В корне проекта `D:\Claude\ZMU\ReadMe.txt` — личная шпаргалка пользователя с ключевыми фактами (финальный образ, порядок лейнов, карта памяти MC68030). Создан 2026-06-09, содержимое на тот момент совпадало с [[assembled-image]].

**How to apply:** Если ключевые факты меняются/дополняются — обновлять и этот файл, чтобы шпаргалка не разошлась с памятью. Это краткий справочник для пользователя, не дублировать в него весь контекст.

⚠️ **Обновлять ПО ХОДУ, а не в конце.** 2026-07-20 файл пролежал нетронутым всю большую сессию (появился третий блок D00636, изменилось понимание HWPN/SWPN, добавился `check_rom_crc.py`) — пользователю пришлось напомнить вопросом «а ты читал ReadMe.txt?». Проверять актуальность файла при каждом существенном новом факте, а не откладывать до сохранения памяти. Синхронизирован 2026-07-20.
