Перечитывание массива 8× X28C512 с правильным подключением. Протокол: 2 чтения подряд не вынимая, проверка `check_dump.py`, оба должны совпасть байт-в-байт.

Имена файлов в `dump/`: `512-N_a.bin` / `512-N_b.bin` (дефис, N = номер чипа 1..8).

⚠️ Суффиксы `_a`/`_b` здесь значат «сохранены ОБА чтения», а не «только этот блок читали дважды». Пользователь верифицирует повторными чтениями каждый чип каждого блока — [[fault-diagnosis-model]], раздел про протокол чтения. По числу файлов в папке о числе чтений не судить.
