Массив из 8 микросхем X28C512 (каждая 64K x 8 = 64 КБ). Разводка:
- Адрес A0–A15 параллельно у всех 8 чипов.
- Данные параллельны парами (1,2)(3,4)(5,6)(7,8) → 4 байтовых лейна = 32 линии данных.
- OE общий на все 8 (одно чтение = 32 бита разом).
- WE параллельны парами = 4 побайтных строба записи (byte-enable внутри 32-битного слова).
- CE двумя группами: банк A = чипы 1,3,5,7; банк B = чипы 2,4,6,8 (взаимоисключающие, CE = 17-й бит адреса).

**Вывод:** организация **128K × 32 бит = 512 КБ**.

ВНИМАНИЕ: первоначальное предположение о порядке лейнов (слово=чип7:чип5:чип3:чип1) ОКАЗАЛОСЬ НЕВЕРНЫМ. Уточнено по структуре собранного образа (см. [[assembled-image]]): лейны чипов (5,6) и (7,8) переставлены — байт2<->байт3. Правильно:
- Слово банка A (D31..D0) = chip5 : chip7 : chip3 : chip1
- Слово банка B (D31..D0) = chip6 : chip8 : chip4 : chip2

**Разрешённые вопросы (по структуре образа, 2026-06-09):**
1. Позиция бита банка: СТАРШИЙ адресный бит — две непрерывные половины (не interleave).
2. Порядок байтов: см. выше (byte0=chip1/2, byte1=chip3/4, byte2=chip7/8, byte3=chip5/6).

**Остался открытый:** порядок половин (банк A или банк B в младших адресах) — нужна карта памяти CPU.
